Blinded annotation: which edited meal photo is better?

This tool is for the SgFood-Edit project team only. Each screen shows an original hawker-meal photo and two edited versions from different methods, in random order and with no method names. Answer two quick questions about each version, then pick the one that better makes the requested change while keeping the rest of the meal. Judge only what you see; do not try to work out which method made which image.

There are about 35 screens (about 10–15 minutes). Every answer is saved as you go, so you can stop and come back with the same link. The first screen is practice and shows you the expected answer.

What to look for

Task 1 · add broccoliAdd a few cooked broccoli florets on top of the existing rice or noodles. The rice or noodles must still be there, and everything else stays the same.
Task 2 · brown riceReplace the white rice with cooked whole-grain brown rice. No white rice should remain, and it should look like real brown rice, not tinted white rice. Everything else stays the same.

Rate each output on its own first, then choose the one that better does the task while keeping the rest of the meal. Grey bars at the image edges are padding; ignore them.

Tap any image to enlarge it. In the enlarged view, switch between the original and each output (keys 0, 1, 2) to spot changes.
